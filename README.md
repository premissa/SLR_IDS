# Online Repository

## A Systematic Review of Machine Learning–Based Anomaly Detection for Network Intrusion Detection Systems

**The repository contains:**

1. SLR_articles.xlsx: exported from Scopus and used for screening the articles. The ranking and categorization columns were added and manually populated. For ranking, https://www.scimagojr.com/ and https://portal.core.edu.au/conf-ranks/ were used.
   
2. SLR.xlsx: the articles are enumerated, and their properties, along with the defined dimensions, are collected. The - sign denotes that no information was found in that particular article for the particular property. For the articles that were not accessible, the properties were determined from publicly available information, such as the title, abstracts and, in some cases, notes.

3. taxonomy.png: the taxonomy diagram.

4. SLR Diagrams.xlsx: the diagrams created for illustration purposes

5. metrics_definitions_nids_v3.xlsx: unified list of the metrics used in the articles in the investigated corpus along with their very short definitions.

6. nids_dataset_summary_v1.xlsx: unified list of the datasets used in the articles with their short description
